
# โปรแกรมจัดการ UDP Custom
 
## ภาพรวม
 
สคริปต์ "โปรแกรมจัดการ UDP Custom" ช่วยเปิดใช้งาน UDP บน VPS ระบบ 64 บิต มีฟังก์ชันสำหรับสร้าง ดูรายการ และจัดการผู้ใช้งาน รวมถึงตั้งค่าช่องทางเชื่อมต่อ VPN สำหรับใช้งานร่วมกับแอปพลิเคชัน HTTP Custom
 
## คุณสมบัติ
 
- เปิดใช้งาน UDP: ติดตั้งและกำหนดค่าเพื่อเปิดใช้งาน UDP บน VPS ระบบ 64 บิต
​
- จัดการผู้ใช้: สามารถสร้าง ดูรายการ และจัดการบัญชีผู้ใช้งานได้
​
- ช่องทางเชื่อมต่อ VPN: ตั้งค่าช่องทางเชื่อมต่อ VPN สำหรับใช้งานร่วมกับแอปพลิเคชัน HTTP Custom
 
## ข้อกำหนดเบื้องต้น
 
- VPS ระบบปฏิบัติการ 64 บิต
​
- สิทธิ์ในการแก้ไขการตั้งค่าเครือข่าย
​
- ติดตั้งแอปพลิเคชัน HTTP Custom บนอุปกรณ์ของคุณแล้ว
 
## วิธีติดตั้ง
 
1. ดาวน์โหลดและรันสคริปต์ติดตั้ง:
    ```sh
    wget "https://raw.githubusercontent.com/noobconner21/UDP-Custom-Script/main/install.sh" -O install.sh && chmod +x install.sh && bash install.sh
    ```

## วิธีใช้งาน

1. **เข้าสู่แผงควบคุม SSLAB UDP**:
    ```sh
    menu
    ```
